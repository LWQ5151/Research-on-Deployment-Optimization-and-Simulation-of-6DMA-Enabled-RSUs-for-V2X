伴随 6G 通信与车联网 V2X 发展，六维可移动天线（6DMA）能够动态调节波束指向，传统静态 RSU 部署策略无法发挥动态天线能力，容易出现高峰覆盖不足、通信资源浪费。

本项目构建**双时间尺度联合优化框架**：

1. **慢时间尺度（离线部署）**：提出**DPS 动态潜力评分 (Dynamic Potential Score)**，综合交通流**时间波动性、空间聚集度、流量幅值**评估候选点位动态适配价值；使用**模拟退火算法 (SA)**求解 RSU 最优部署方案。对比基线：Traffic‑Greedy 平均流量贪心、I‑RSU 路口优先部署、Random 随机部署。
2. **快时间尺度（在线波束调度）**：提出**GSAS 全局顺序角度搜索算法**，解决多 RSU 波束重叠区域流量重复计数问题，实现低复杂度毫秒级实时波束角度分配；实现 3 种调度策略：静态最优 Static‑Optimal、预测动态 Predictive‑Dynamic、先知动态 Oracle‑Dynamic（理论上界）。

基于成都市真实 GPS 出租车轨迹数据集开展仿真实验，验证 DPS‑SA 部署方案与 GSAS 波束调度算法的覆盖性能、动态增益与参数灵敏度。
